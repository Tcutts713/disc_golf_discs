This dataset of discgolf discs was created by scrapping the website trydiscs.com

The dataset is has been updated as of 6/5/26 and contains most discs available on the market.  
**THIS IS NOT A COMPLETE DATASET OF ALL DISCGOLF DISCS**
PDGA has 2382 discs approved to sanctioned play
This dataset contains 2110 discs

Dataset configuration:
manufacturer, disc_name, speed, glide, turn, fade, stability, disc_type, discontinued

Stability is subjective but for the purpose of this dataset any disc of a score >= 1.5 is overstable, <= -1.5 understable, and inbetween is stable or neutral

Disc type is based on speed: <= 4 is putt & approach, 5 - 6 are mid ranges, 7 - 10 are fairway drivers, and 11+ are distance drivers
